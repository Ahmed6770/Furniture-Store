# LOOMA — Furniture Store

A modern furniture e-commerce website built with React and Tailwind CSS.

LOOMA provides a clean and responsive shopping experience for browsing furniture, viewing product details, managing a shopping cart, and completing a front-end checkout flow.

## Features

- Responsive modern furniture store UI
- Product browsing and search
- Filtering and sorting
- Product details
- Add to cart from product cards and product details
- Quantity management
- Cart calculations
- Free shipping calculation
- Cart persistence with localStorage
- Checkout form
- Cash on Delivery
- Order confirmation
- Responsive layouts for desktop, tablet, and mobile

## Tech Stack

- React
- React Router
- Tailwind CSS
- Context API
- localStorage
- Vite
- Lucide React
